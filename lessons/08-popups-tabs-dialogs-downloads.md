# Lesson 08 · New tabs, popups, dialogs and downloads

> **Goal:** handle the four things that make PAD bots hang: new tabs, popup windows, alert/confirm boxes, and file downloads.

## PAD → Playwright mapping

| PAD | Playwright |
|---|---|
| **Attach to running browser** (to grab a new tab by title/URL) | `with page.context.expect_page() as info: <click>` → `new_tab = info.value` |
| Popup window opened by `window.open` | `with page.expect_popup() as info: <click>` → `popup = info.value` |
| **Close web browser** (just that tab) | `new_tab.close()` |
| **Handle web page dialog** → Click OK | `page.once("dialog", lambda d: d.accept())` **before** the click |
| **Handle web page dialog** → Click Cancel | `page.once("dialog", lambda d: d.dismiss())` |
| Dialog with text input (prompt) | `d.accept("my text")` |
| Get dialog message | `d.message` |
| **Download from web** / click link + wait for file in Downloads folder | `with page.expect_download() as info: <click>` → `info.value.save_as("path")` |

## The key idea: "get ready, then click"

In PAD you click first and then go looking for the new tab or dialog. In Playwright you **tell it what you're expecting first**, then click inside a `with` block. This avoids the race where the tab opens before your bot starts looking for it.

### New tab

```python
with page.context.expect_page() as tab_info:
    page.get_by_role("link", name="Open enrollment guide (new tab)").click()
tab = tab_info.value          # a normal Page. Use get_by_..., fill, click as usual
tab.wait_for_load_state()
print(tab.title())
tab.close()                   # the original `page` is still there, untouched
```

### Popup window

```python
with page.expect_popup() as popup_info:
    page.get_by_role("button", name="View fee schedule").click()
popup = popup_info.value
print(popup.get_by_test_id("fee-group").inner_text())   # $709.00
```

### alert / confirm / prompt

By default Playwright **auto-dismisses** dialogs (clicks Cancel) so your bot never freezes. To choose the answer, register a handler *before* the click:

```python
page.once("dialog", lambda dialog: dialog.accept())     # OK, only for the NEXT dialog
page.get_by_role("button", name="Withdraw application").click()
```

`lambda dialog: dialog.accept()` is a tiny one-line function. `page.once` runs it for the next dialog only; `page.on` would run it for every dialog.

### Downloads

```python
with page.expect_download() as dl_info:
    page.get_by_role("button", name="Generate report").click()
download = dl_info.value
download.save_as(f"output/{download.suggested_filename}")
```

This works even when the file is generated by JavaScript and has no fixed URL (the *Generate report* button), where PAD's *Download from web* can't help.
